Zorunlu Bildirim

Uyarı: Bu rapor Finance X platformu tarafından otomatik üretilmiştir. Python deterministic hesaplamalar + LLM narrative bloklar hibrit modeliyle hazırlanmış olup, yatırım tavsiyesi değildir. Rapor veri kaynağı sınırlıdır ve profesyonel bir yatırım danışmanının yerini tutmaz. Sermaye Piyasası Kurulu (SPK) düzenlemeleri çerçevesinde herhangi bir karar almadan önce profesyonel danışmanlık alınız.
Metodoloji: Python kap_watch → event_classification (kural tabanlı) → event_impact_mapper (template tablosu) | parse_standardization (pdfplumber) → reconciliation (BS/IS/CF identity) → financial_analysis (engine DCF, ratios) | macro_analysis (TCMB) → technical_analysis (TradingView/yfinance fallback) → qa_review (rubric scoring) → strategic_synthesis (signal convergence) → report_formatter (template render). Narrative blokları LLM (Claude) üzerinden enjekte edilir.
