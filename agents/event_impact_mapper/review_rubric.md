# Event Impact Mapper Agent — Review Rubric
## Finance X Platform | Quality Standards for Event-to-Financial-Impact Mapping

---

## Critical Pass/Fail Rules

1. **Every impact map must cite the originating KAP disclosure ID.** Uncited event sources = automatic rejection.
2. **Effect type must not exceed classification confidence.** If event is classified `plausible`, impact can be at most `plausible`, not `confirmed`.
3. **Quantification estimates must state their formula and inputs.** Bare numbers without methodology = revision required.
4. **Management change events must not be mapped to specific financial impacts** without explicit, post-change strategy disclosure.
5. **No investment recommendations.** Any directional language that could be construed as buy/sell advice = scope violation.

---

## Scoring Standards

### Evidence Sufficiency (30%)
- 1.0: Every impact map cites KAP document ID, IFRS standard where applicable, and financial context source
- 0.7: Most maps cited; 1–2 minor citations missing
- 0.4: Multiple events lack source citation
- 0.0: No event citations

### Confidence Calibration (25%)
- 1.0: All confidence labels aligned with event clarity and disclosure completeness
- 0.7: Minor miscalibration; no speculative claims labeled as confirmed
- 0.2: Speculative impacts labeled confirmed or plausible; hard reject trigger

### Claim Support (25%)
- 1.0: Every impact direction derivable from standard financial theory and cited disclosure
- 0.7: Most mappings well-supported; minor inferential gaps noted
- 0.2: Impact directions asserted without supporting rationale

### Completeness (10%)
- 1.0: All 10 event type categories represented where events exist; all required fields populated
- 0.6: Some secondary effects or risks missing
- 0.0: Core impact fields (statements, line items, direction) missing

### Scope Compliance (10%)
- 1.0: No event classification; no investment recommendations
- 0.0: Investment recommendation present; event classification overridden
