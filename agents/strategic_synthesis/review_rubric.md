# Strategic Synthesis Agent — Review Rubric

## Critical Pass/Fail Rules
1. Every claim in convergence/divergence maps must cite a specialist output_id.
2. No new claims originating in synthesis (no unprovided analysis).
3. All CEO-flagged contradictions must appear in contradiction_resolutions or divergence_map.
4. Synthesis confidence cannot exceed weakest critical input's confidence.
5. No investment recommendations.

## Scoring
- Evidence Sufficiency (30%): All claims cite specialist output IDs = 1.0
- Confidence Calibration (25%): Synthesis confidence does not exceed input base
- Claim Support (25%): No claims beyond what specialist inputs contain
- Completeness (10%): All approved specialist outputs referenced
- Scope Compliance (10%): No investment recommendations; no new analysis
