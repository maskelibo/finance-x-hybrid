# Havacılık Sektörü — Bilgi Modülü

## Zorunlu Ek Metrikler
- EBITDAR (EBITDA + Kira Gideri) — ZORUNLU
- RPK (Revenue Passenger Kilometer)
- ASK (Available Seat Kilometer)
- Load Factor (Doluluk Oranı)
- CASK (Cost per ASK)
- RASK (Revenue per ASK)
- Yield (Birim Gelir)
- Uçak filosu yaş ortalaması

## Değerleme Yaklaşımı
- EV/EBITDAR birincil çarpan (kira normalizasyonu)
- DCF: FCF hesabında IFRS16 kira ayarlaması zorunlu
- Peer: global airline peer set (IAG, LHA, AFR-KLM, DAL, UAL)

## Benchmark Referansları
- Load Factor: %80–90
- EBITDAR Marjı: %18–30
- Net Borç/EBITDAR: 2x–5x
- CASK (ex-fuel): sektör alt çeyrek hedef

## Sektöre Özgü Riskler
- Jet yakıt fiyat volatilitesi (Brent korelasyonu)
- Kur riski (gelir USD/EUR, gider TRY karışık)
- Slot hakları ve uçuş izinleri
- Mevsimsellik (Q2-Q3 pik, Q1-Q4 düşük)
