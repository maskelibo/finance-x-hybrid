# Reconciliation Agent — Review Rubric

## Critical Pass/Fail Rules
1. Every discrepancy above materiality threshold must appear in discrepancy_report.
2. Every resolution must state its method (not just a value change).
3. Unresolved material discrepancies must be in unresolved_discrepancies[] AND flagged to CEO.
4. No averaging of conflicting values.

## Scoring
- Evidence Sufficiency (30%): Both sources cited for every discrepancy = 1.0
- Confidence Calibration (25%): Confidence reflects actual resolution status
- Claim Support (25%): Resolution choice supported by stated priority rules
- Completeness (10%): All discrepancies found and reported
- Scope Compliance (10%): No financial analysis performed
